**Data Pipeline using Power BI for Logistics Data and Indicator Analysis**<br>
Using TXT files and Power BI, this project helps a supermarket chain track its logistics and key metrics.
The main goal is to avoid overstock and keep stores from running out of products. By keeping an eye on
things, we can prioritize shipping for items with critical stock levels and schedule supplier deliveries at
distribution centers running low. This makes it easy to restock stores right when they expect a sales boost
from promotions, marketing campaigns, and events.<br>

**Pipeline de Dados usando Power BI para Análise de Dados e Indicadores Logísticos**<br>
Utilizando arquivos no formato txt e a ferramenta **Power BI**, o objetivo deste processo é analisar dados e indicadores
logístico de uma rede de supermercados, evitando estoque em excesso (Overstock) e análise de ruptura de produtos nas lojas,
com o objetivo de priorizar o envio de pedidos que estão com estoque crítico e agendar fornecedores para entrega de cargas
nos centros de distribuições que possuem estoque baixo, assim, sendo possível realizar recargas de produtos nas lojas que
podem ter um aumento nas vendas, seja em função de promoçoes, campanhas, etc.<br>
